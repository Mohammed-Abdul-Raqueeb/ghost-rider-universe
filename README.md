# 🔥 Ghost Rider Universe

A cinematic, interactive fan-made website dedicated to the **Ghost Rider** comic universe.

Explore Ghost Rider's origins, powers, characters, villains, mythology, comic history, major storylines, and more through a highly visual and immersive web experience.

> **Fan Project:** This website is an unofficial, non-commercial fan project and is not affiliated with or endorsed by Marvel Entertainment.

## ✨ Features

* 🎬 Cinematic Ghost Rider video experience
* 🔥 Immersive dark supernatural visual design
* 💀 Ghost Rider powers and abilities
* 📖 Origins, lore, and mythology
* 👤 Characters and villains
* 📚 Comic history and major storylines
* 🏍️ Ghost Rider vehicles
* 🌎 Timeline and universe exploration
* 🎞️ Movies and media
* 🖼️ Gallery and visual content
* 📱 Fully responsive design
* ⚡ Smooth animations and page transitions
* 🔎 Structured navigation and exploration

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Mohammed-Abdul-Raqueeb/ghost-rider-universe.git
```

Navigate to the project:

```bash
cd ghost-rider-universe
```

Install dependencies if required:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local development URL shown in your terminal.

## 🎨 Design Philosophy

The project is designed around a cinematic interpretation of the Ghost Rider universe, combining:

* Hellfire-inspired visuals
* Dark atmospheric backgrounds
* Metallic elements
* Smoke and particle effects
* Dramatic typography
* Cinematic motion
* Comic-inspired layouts
* Interactive storytelling

The goal is to make browsing the Ghost Rider universe feel like an immersive digital experience rather than a traditional information website.

## 📱 Responsive Design

The website is designed to work across:

* Desktop
* Laptop
* Tablet
* Mobile

Layouts, navigation, typography, media, and interactions adapt to different screen sizes.
