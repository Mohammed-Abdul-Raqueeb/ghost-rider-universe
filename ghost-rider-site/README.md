# Ghost Rider — Spirit of Vengeance · static site

A 28-page (plus 404) static reference site with a persistent full-screen background video.

## Deploy
Upload the contents of `site/` to any static host (Netlify, Vercel, GitHub Pages, S3, nginx).
Serve it over HTTP(S): the in-place page transitions use `fetch`, which browsers block on `file://`
(the site still works from a file:// URL — links simply do full page loads).

Before deploying, set `SITE_URL` in `build.py` to your real origin and rebuild so that canonical
URLs, Open Graph tags, `sitemap.xml` and `robots.txt` point at the right domain.

## Rebuild
    python3 build.py

Pages live in `pages/*.py` (one module per page; each returns a dict with slug/title/desc/body).
Shared layout, navigation tree, footer, breadcrumbs, JSON-LD, sitemap, manifest and the search
index are generated by `build.py`. Styling is `site/assets/css/main.css`; behaviour is
`site/assets/js/main.js`. No build tooling or runtime dependencies beyond Python 3.

## Video
`site/assets/video/`
- `ghost-rider-bg.mp4`     1280×720 H.264, muted — desktop background
- `ghost-rider-bg-sd.mp4`  854×480 — phones and data-saver connections
- `ghost-rider-bg.webm`    1280×720 VP9 — browsers without H.264
- `ghost-rider-theater.mp4` 720p with the original audio — Videos page

The source clip was a vertical phone capture stored rotated; it was transposed to landscape and
trimmed to 28.5 s. Stills in `site/assets/img/stills/` are frames from the same clip.
